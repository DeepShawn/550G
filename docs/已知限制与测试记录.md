## 需要在 Windows 上重点验证的风险

1. **`setMask` + 透明窗口**：Windows 分层窗口上的遮罩命中与边缘效果需实测（W14）。如有异常，可设环境变量 `DESKTOP_PETS_NO_MASK=1` 关闭遮罩对比。
2. **DPI**：使用 `PassThrough` 缩放策略，位图按 devicePixelRatio 预缩放；150%/200% 与跨不同 DPI 屏拖动需实测（W13/W23）。
3. **托盘不可用**：可设 `DESKTOP_PETS_FORCE_NO_TRAY=1` 模拟（W12）。
4. **单实例**：第二次启动通过本地套接字通知旧实例；陈旧锁按 PID 处理（W19）。
5. **PyInstaller 冻结**：资源路径、Qt 平台插件、窗口模式无 stderr 时的日志（W01–W04，W18）。
6. 呼吸浮动以 25 FPS 重绘，待机 CPU/内存需在 W22 中实测。
