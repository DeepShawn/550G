整理日期：2026-11-15。目标平台：Windows 10/11 x64。

本包是**开发计划、原始源码和资源规格交接包**，不是已完成的新版桌宠，不包含已构建或已验证的 Windows EXE。原版 7 个文件完整保留，没有把计划冒充已实现功能。

## 交接方式

1. 将本 ZIP 上传给 Claude，同时附上本轮聊天里的双人桌宠参考图。
2. 把 `07_给Claude的启动指令.md` 全文发送给 Claude。
3. 先阅读计划与源码审计，再按里程碑实施；Windows 原生桌面方向已经确定。
4. 先跑通交互、状态切换和发布流程，再替换正式高清素材；临时素材必须标明为占位资源。

## 已确定与暂定

- 真正的 Windows 原生桌面应用：透明、置顶、两个角色同时存在，不依赖常驻浏览器。
- 独立拖动、点击对白、待机、眨眼、睡觉、卖萌；角色右键与系统托盘支持控制，隐藏后能恢复。
- 550G 是蓝色主题；前辈GPT 是浅白绿色渐变长发、白裙。
- 用户优先要“清晰一点，有表情变化就行”，不要求先实现走路、复杂骨骼或联网 AI。
- 发色 A/B/C 未得到最终确认。先按**灰白发＋蓝色服装**保留原设定；C 方案的蓝色挑染待确认，不覆盖成大面积蓝发。此项不阻塞程序开发，正式批量绘制前集中核对一次。
