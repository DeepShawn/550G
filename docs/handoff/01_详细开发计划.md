# 详细开发计划

## 1. 产品目标

交付解压即可启动的 Windows 10/11 x64 双人桌宠。打开后两位坐姿 Q 版角色出现在桌面，可分别拖动，点击得到短对白，看到清楚的眨眼、卖萌和睡眠变化。隐藏能找回，退出不残留后台进程。

最终用户无需安装 Python、打开浏览器或配置密钥。开发期可以使用 Python。当前不包含联网聊天、语音、账号、文件读取、自动更新、开机启动或复杂走路动画。

## 2. 优先级

| 优先级 | 功能 | 完成标准 |
| --- | --- | --- |
| P0 | 透明置顶双窗口 | 两个原生独立窗口同时存在，桌面无矩形底色 |
| P0 | 独立拖动与单击 | 拖 A 不移动 B；拖动不出对白，单击才对话 |
| P0 | 表情状态 | 每位至少待机、眨眼、卖萌、睡觉四种可辨识状态 |
| P0 | 隐藏/显示/退出 | 单只和全部控制可用，隐藏后有恢复入口 |
| P0 | 清晰角色 | 正式 RGBA 素材，默认和放大显示无明显白边、模糊和错位 |
| P0 | Windows 发布 | 独立运行目录 ZIP，在无 Python 的 Windows 机器验证 |
| P1 | 位置和大小记忆 | 重启恢复，显示器布局变化后可找回 |
| P1 | 自动睡眠与手动切换 | 空闲睡眠、点击唤醒，右键可测试所有表情 |
| P1 | 诊断与首次提示 | 有启动失败日志，首次说明托盘恢复方式 |
| P2 | 双人互动 | 一起玩耍、联动对白、靠近反应 |
| P2 | 额外动作 | 疑惑、生气、喝饮料、更多睡姿 |

P1 在第一版正式发布前完成；P2 延后，不作为第一版完成条件。

## 3. 里程碑

### M0：接管与基线复现（约半个工作日）

- 阅读交接包，另建开发目录，不覆盖 source_original。
- Windows Python 3.11 x64 建虚拟环境，安装依赖，启动原型。
- 记录系统、Python、PySide6 版本及原型表现；保留截图。
- 建 CHANGELOG、任务清单和最小测试入口。
- 交付：可复现的启动步骤和问题记录。门槛：确实看到两个独立桌面窗口。

### M1：可靠桌面交互（约 1 个工作日）

- 分离应用控制器与角色窗口，修复按下就说话的问题。
- 浮动改为绘制层偏移，避免周期性移动整个窗口。
- 统一角色/托盘菜单，添加单只显示、显示全部、恢复到主屏。
- 处理无托盘场景，不能隐藏所有入口后失联。
- 加入位置/大小保存、坐标可见性修复、重复启动处理和退出清理。
- 交付：可靠双窗口原型和交互测试结果。

### M2：状态与表情（约 1 个工作日）

- 支持 idle、blink、cute、sleep；使用单调时间计算。
- 用占位帧验证接口；真正验收时必须接入能看到差异的表情素材。
- 单击卖萌并说话；随机眨眼；空闲睡眠；点击睡眠角色唤醒。
- 右键可演示状态，两只的状态、对白与计时互不干扰。
- 隐藏时停止重绘，显示时重置时间基准。
- 交付：四状态演示与状态切换、缺帧回退测试。

### M3：高清角色素材（约 1～3 个工作日，视返工而定）

- 每位先做一张待机稿，核对身份、发色、服装、姿势和脸部大小。
- 批量绘制前集中确认发色与待机稿；程序开发可继续。
- 每位至少四张同画布全身透明 PNG，推荐加一张半闭眼帧。
- 检查透明边缘、五官位置、脚底锚点，不得切换表情时整个人跳动。
- 在 Windows 默认尺寸、150%/200% DPI 下查看。
- 交付：素材、预览拼图、资源清单、来源/使用范围记录。

### M4：打包与回归（约 1～2 个工作日）

- Windows 使用 PyInstaller 构建 onedir 包，确认资源路径与启动目录无关。
- 无 Python、普通用户权限、中文路径和断网环境中启动。
- 完成 Windows 10/11、DPI、多屏、隐藏恢复和长时间运行检查。
- 锁定已验证依赖，更新版本、说明、变更记录与限制。
- 交付：可运行 ZIP、对应源码 ZIP、素材清单、实际测试记录。

总工作量初估 4.5～7.5 个工作日，不是交付日期承诺。素材审核、设备条件与返工会影响进度。

## 4. 第一版完成定义

- P0、P1 完成，验收表中的发布阻断项通过。
- 两位符合设定；表情直接可辨认，不能只放大旧素材冒充高清重绘。
- 有真实可运行 Windows 包及实机记录。未测项标明“未测”。
- 发布包不含开发虚拟环境、缓存、临时文件、密钥或个人路径。

## 5. 决策与风险

- 沿用 PySide6，复用原型。Qt 包体通常不小；“轻量”指无浏览器和合理开销，不承诺几 MB 的体积。
- 发色暂按灰白主体；蓝色挑染未确认。
- 参考图是低分辨率拼图，只用于风格，不直接裁成正式帧。
- 置顶覆盖普通桌面和普通应用；独占全屏游戏、安全桌面不属于保证范围。
- 素材尚未完成时只能交付明确标注的工程预览，不应宣称最终视觉完成。
