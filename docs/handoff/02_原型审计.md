# 原型静态审计

对象：source_original 下 Python、BAT、依赖和三份 SVG。此次未启动 Windows 程序，以下是静态审计，不是实机验证。

## 已有实现

- PySide6 QWidget，FramelessWindowHint、WindowStaysOnTopHint、Tool、WA_TranslucentBackground。
- 两个 Pet 实例各自有坐标、拖动偏移、对白和定时器。
- QSvgRenderer 渲染，45 ms 定时器让窗口轻微上下浮动。
- 左键显示轮播对白；角色右键可说话、隐藏单只/全部、退出。
- 托盘可显示全部、隐藏全部、关于、退出，双击显示全部。
- 已是原生桌面技术，不需要换成 Electron 或网页。

## 确定的差距

| 位置 | 观察 | 后续处理 |
| --- | --- | --- |
| Pet.mousePressEvent | 左键按下立即 say() | 释放时根据移动阈值区分点击与拖动 |
| Pet.animate | 每次 move() 整个窗口 | 改为绘制偏移；基础位置只由拖动与恢复修改 |
| Pet.__init__/paintEvent | 180×220 窗口，角色区约 180×180 | 独立规划角色画布、气泡空间，保持纵横比 |
| 两张角色 SVG | 固定表情，细节简单 | 正式高清素材与不同表情帧 |
| 动画 | 只有浮动和按 tick 扣减气泡时间 | 单调时间状态机和实际表情变化 |
| Pet.menu | 没有显示入口、状态选择或尺寸设置 | 增加显示另一只/全部、表情、大小 |
| 托盘初始化 | 未处理托盘不可用 | 保证隐藏后仍有可见控制入口 |
| 位置 | 未保存、可拖离屏 | 配置持久化、屏幕约束、位置重置 |
| 隐藏 | timer 继续运行 | 暂停无意义动画工作 |
| 生命周期 | 无重复启动控制、日志 | 单实例和恢复已有实例的本地通道，用户目录日志 |
| requirements.txt | PySide6>=6.6,<7 | Windows 验证后锁定依赖 |
| 启动桌宠.bat | 每次 pip install，仅寻找 py | 开发脚本使用虚拟环境；最终给用户 EXE |
| 关于文本 | 使用字面量反斜杠 n | 改成真实换行，统一版本信息 |
