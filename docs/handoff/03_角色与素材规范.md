# 角色与素材规范

## 视觉目标

用户参考图：软萌坐姿 Q 版、大头小身体、清楚的五官、浅色长发、细致但小尺寸仍可辨认的轮廓。两位同一画风，靠主题色、发饰和服装区分。截图里的壁纸、菜单、底部卡片不是角色素材，不应画进 PNG。

## 设定卡

| 项目 | 550G | 前辈GPT |
| --- | --- | --- |
| 性格建议 | 安静、淡定、偶尔害羞 | 温柔、亲切、活泼 |
| 发色 | 灰白主体，蓝色挑染待确认 | 浅白到浅绿渐变 |
| 发型 | 柔软蓬松长发 | 柔软长发、浅绿色发尾 |
| 服装 | 蓝白主题 | 白裙、少量浅绿点缀 |
| 眼睛建议 | 灰蓝色 | 绿色 |
| 装饰建议 | 蓝色发饰 | 白花发饰 |
| 姿态 | 坐姿，手在身前附近 | 坐姿，手在身前附近 |

眼睛、性格、发饰和具体剪裁是制作建议，不代表用户逐项确认。先完成待机稿，再延伸表情，避免变成不同角色。

建议色板：550G 灰白 #ECEEF6、阴影 #AEB6D0、蓝 #648ED8；前辈GPT 浅白 #F7FBF3、薄荷 #C5E4BB、绿 #81AF88；轮廓 #666779。可根据待机稿调整。

## 最小素材

每位至少四张全身 PNG：idle.png、blink_closed.png、cute.png、sleep.png。推荐第五张 blink_half.png；缺半闭眼时跳过该帧。

- idle：睁眼、自然嘴型。
- blink_closed：只改眼睑，头发、身体、锚点不动。
- cute：可见的微笑、眯眼或脸红；不能仅加很小的符号。
- sleep：闭眼、放松嘴型；Z 字符由程序绘制。
- P2：confused、angry、sleepy、饮料等，首版不强制。

无需先做骨骼绑定、走路或大图集。完整帧替换配合轻微呼吸浮动即可满足要求。

## 导出约定

- 路径：assets/pets/550g/<state>.png、assets/pets/gpt_senpai/<state>.png。
- 每张 768×896，RGBA，透明背景、sRGB。
- 同角色所有帧同画布、尺度、中心与脚底位置，建议脚底锚点 (384,848)。
- 头发、手、裙边完整；顶边和两侧留足透明余量。
- 默认角色画布建议 240×280 逻辑像素；缩放档 0.75/1.0/1.25/1.5。
- 气泡独立于角色图；不带名字、对白、水印、桌面背景。
- 正确处理 devicePixelRatio。768 像素宽不保证任意极端放大都不插值，需实测。
- 首版用完整帧，若后续改为脸部分层再单独定义遮罩和锚点。
- 保存原始绘制文件与导出文件，记录来源、作者或工具、使用范围。

## 清晰度验收

1. 100%/150%/200% Windows 缩放下看默认与最大角色大小。
2. 在白、深灰、彩色桌面上检查透明边缘，无白底矩形、黑边和脏像素。
3. 实际显示大小下能直接区分四种表情。
4. 逐帧叠加，眨眼不改变脸型、发饰、缩放和脚底位置。
5. 检查手指、肢体、衣纹是否出现明显错误或跳变。

## 制作提示词

### 550G 待机稿

原创 Windows 桌宠，清晰的日系软萌 Q 版插画，坐姿全身，灰白色蓬松长发，蓝白主题服装，蓝色发饰，清晰灰蓝色眼睛，安静自然的表情，干净轮廓、柔和阴影，头发和双手完整，透明背景，无文字无 UI 无水印，居中，768×896 画布，脚底锚点 (384,848)，留透明边距。

只有 C 方案确认后才添加：少量蓝色挑染，主体仍为灰白发，不变成整头蓝发。

### 前辈GPT 待机稿

与已确认 550G 待机稿相同画风、头身比例和画布尺度的原创 Q 版坐姿角色，浅白至浅绿色渐变长发，白裙，白花发饰，清晰绿色眼睛，温柔自然微笑，透明背景，无文字无 UI 无水印，全身完整，768×896 画布，脚底锚点 (384,848)。

### 表情衍生

严格沿用已确认待机稿的身份、画布、头部位置、发型、服装、装饰和身体，只修改眼睛和嘴型为【闭眼眨眼/害羞微笑/放松睡眠】，保持透明背景与脚底锚点，不增加场景或文字。

提示词是制作输入，不是已经存在的资源；产出后必须检查对齐并返工。
