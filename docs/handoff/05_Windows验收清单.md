## 性能记录

固定机器和显示尺寸，记录 OS、CPU、RAM、构建版本。启动稳定后待机 5 分钟，记录 CPU、内存；全隐藏后再测，检查无忙循环。建议目标：普通现代机器待机 CPU 平均约 1% 或更低、工作集尽量控制在 200 MB 内；这些是优化目标，不是当前实测承诺。30 分钟结束对比内存趋势。
