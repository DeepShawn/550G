# 550G × 前辈GPT 桌宠 v0.3.0（开发预览版）

Windows 10/11 x64 双人桌宠：两位坐姿 Q 版角色常驻桌面，透明、置顶、各自拖动；单击说话卖萌，随机眨眼，空闲睡觉，单击唤醒；右键和托盘可隐藏/显示/恢复/退出。离线运行，无需安装 Python。

## 下载与运行

1. 下载 `550G_GPT_DesktopPets_v0.3.0-dev-preview_win_x64.zip`，**解压整个文件夹**。
2. 双击 `DesktopPets550G.exe`。
3. 程序未做代码签名，Windows SmartScreen 可能提示“已保护你的电脑”：确认文件来自本页面后，点“更多信息 → 仍要运行”。

操作：左键单击说话，按住拖动；右键角色打开菜单（表情、大小、隐藏、显示另一只、恢复位置、退出）。隐藏后从任务栏托盘（可能在“^”里）单击/双击图标找回，或再次运行 EXE。

## 本版内容

- 角色形象直接取自概念图中的表情贴纸：待机、眨眼、卖萌、睡觉，以及 550G 的惊讶/生气、前辈GPT 的开心/疑惑。
- 点击与拖动分离、透明区域不挡鼠标、位置与大小记忆、多屏与离屏恢复、托盘不可用时的控制窗口、防重复启动、日志。

## 预览版说明（请先看）

- 已在 GitHub Actions 的 Windows 构建机上通过 60 项自动测试和打包后自检；**尚未在真实 Windows 电脑上人工验收**（透明效果、拖动手感、DPI、多屏）。遇到问题请附上日志：右键角色 → 关于… 里有日志路径。
- 原图贴纸较小，150%/200% 屏幕缩放或“特大”尺寸下画面偏软。
