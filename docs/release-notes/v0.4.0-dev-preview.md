# 550G × 前辈GPT 桌宠 v0.4.0（开发预览版）

**角色换成新参考图的形象**：550G 抱着企鹅抱枕，前辈GPT 双手托腮，像素直接取自参考图，比 v0.3.0 清晰很多。

## 下载与运行

1. 下载 `550G_GPT_DesktopPets_v0.4.0-dev-preview_win_x64.zip`，**解压整个文件夹**。
2. 双击 `DesktopPets550G.exe`。
3. 程序未做代码签名，Windows SmartScreen 可能提示“已保护你的电脑”：确认文件来自本页面后，点“更多信息 → 仍要运行”。

操作：左键单击说话，按住拖动；右键角色打开菜单（表情、大小、隐藏、显示另一只、恢复位置、退出）。隐藏后从任务栏托盘（可能在“^”里）单击/双击图标找回，或再次运行 EXE。

## 本版变化

- 新形象：待机、眨眼、卖萌（^ ^ 笑眼 + 脸红）、睡觉（闭眼 + 飘 Z）。
- 气泡改成参考图里的胶囊样式，名字后带爱心 / 四叶草。
- 托盘和程序图标换成两位新头像。
- 旧画风的惊讶/生气/开心/疑惑表情已移除（和新形象不一致）。

## 预览版说明

- 参考图每位只有一个姿势，所以卖萌、睡觉是同一坐姿换五官，不是新动作；有同姿势的表情原稿可以直接替换。
- 已在 GitHub Actions 的 Windows 构建机上通过自动测试和打包后自检；**尚未在真实 Windows 电脑上人工验收**。遇到问题请附上日志：右键角色 → 关于… 里有日志路径。
- 不含联网聊天、语音、开机启动、自动更新。
