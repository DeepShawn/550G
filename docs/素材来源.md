# 素材来源与使用范围

## 角色帧（v0.4.0 起）

角色形象**直接取自用户参考图 v2** `docs/handoff/resources/user_concept_v2.png`（1402×1122）：550G 抱企鹅抱枕坐着、前辈GPT 双手托腮坐着。像素来自原图，不重新绘制；原图中每位角色约 650 px 高，抠出后按 0.987 倍放进画布，**没有放大**，因此比 v0.3.0 清晰得多。

| 帧 | 来源 |
| --- | --- |
| idle 待机 | 参考图角色本体（`tools/extract_characters.py`） |
| blink_half / blink_closed | 由 idle 只重画眼睛（`tools/make_expression_frames.py`） |
| cute 卖萌 | 由 idle 改为 ^ ^ 笑眼 + 腮红 + 笑嘴 |
| sleep 睡觉 | 由 idle 改为放松闭眼 + 小嘴；Z 由程序绘制 |

参考图每位只有一个姿势，所以卖萌、睡觉是同一坐姿换五官，不是新动作。

### 抠图流程（`tools/extract_characters.py`，参数记录在 `art_source/reference_extraction.json`）

1. isnet-anime 动漫人物分割模型（rembg 发布的 `isnet-anime.onnx`，SHA-256 `f15622d8…6e99`，未提交到仓库）得到前景；气泡、星星、!!、?、底部工具条、背景自动排除；
2. 两人头发在 x≈680～830 交叠：用颜色分数 (g−b)+2(g−r) 区分（550G 灰白偏蓝约 −12，前辈GPT 薄荷绿约 +7～+15）；
3. 被对方头发遮住的小缺口用自身周围颜色补齐；交叠带内撕开的细发丝做开运算清理；
4. 半透明边缘借用内部实色，去掉背景浅蓝和地面阴影带来的暗边；
5. 两人同一缩放（保持参考图里的相对大小），水平居中、底边对齐脚底锚点 (384,848)。

### 限制

- 两人交叠处（550G 右侧、前辈GPT 左侧）的发梢是从重叠处分开的，近看边缘略不自然；正常显示大小下不明显。
- 卖萌/睡觉/眨眼的五官是程序重画的线条，画风比原图简单。有原画师的同姿势表情稿时，按同名 PNG 替换即可（768×896 RGBA，脚底锚点 384,848），代码无需修改。
- v0.3.0 的额外表情（惊讶/生气/开心/疑惑）来自旧概念图，画风与新形象不一致，已移除；`emote` 机制保留，`pets.json` 的 `extras` 可再加。
