# 素材来源与使用范围

| 文件 | 来源 | 状态 | 使用范围 |
| --- | --- | --- | --- |
| assets/pets/550g/{idle,blink_half,blink_closed,cute,sleep}.png | `tools/make_placeholder_art.py` 程序绘制的矢量图形渲染（源 SVG 在 `art_source/placeholder_svg/`） | **工程占位** | 本项目内部开发/预览 |
| assets/pets/gpt_senpai/*.png | 同上 | **工程占位** | 同上 |
| assets/tray.png / tray.ico | 同脚本 `tray_svg()` 生成 | 占位（可用于预览版） | 同上 |
| source_original/assets/*.svg | 用户原始 v1 原型 | 历史基线，运行时不再使用 | 保留对照 |
| docs/handoff/resources/user_concept.png | 用户在对话中提供的概念拼图 | 仅作风格参考，**不裁切为正式帧** | 参考 |

所有占位帧：768×896 RGBA、sRGB、透明背景，脚底锚点 (384,848)；同一角色各帧共享身体/头发/服装图层，只替换眼睛、嘴和腮红，`tools/validate_assets.py` 校验对齐。

## 仍然缺少（正式发布阻断）

- 两位角色的**正式高清立绘**（每位至少 idle / blink_closed / cute / sleep，推荐 blink_half），需与参考图统一画风。
- 替换方法：把新 PNG 按同名放入 `assets/pets/<id>/`，确认通过 `python tools/validate_assets.py`，然后把 `assets/pets.json` 中对应角色的 `"placeholder"` 改为 `false`，并在本表记录作者/工具与授权范围。`build-windows.ps1 -Release` 会拒绝仍为占位的素材。
- 外部参考链接（见 `docs/handoff/resources/参考图说明.md`）未下载、未获授权，不得直接使用。

## 正式绘制前需要用户集中确认一次

1. 550G 发色：当前按“灰白主体 + 蓝色服装/发饰”，**未加蓝色挑染**（C 方案待确认）。
2. 两张待机稿（idle）的身份、发色、服装、坐姿、脸部大小。确认后再批量衍生表情。
