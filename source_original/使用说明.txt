550G × 前辈GPT Windows 桌宠｜第一版

角色：
- 550G：灰白发、蓝色主题
- 前辈GPT：浅白绿色渐变长发、白裙

功能：
- 两只桌宠同时显示，透明背景、窗口置顶
- 鼠标左键拖动；点击角色显示对话气泡
- 右键角色：说句话、隐藏单只、隐藏全部、退出
- 系统托盘图标右键可显示/隐藏/退出；双击托盘图标可重新显示

运行：
1. Windows 10/11，安装 Python 3.10 或更新版本：https://www.python.org/downloads/windows/
2. 安装时勾选 Add Python to PATH。
3. 解压整个文件夹，双击“启动桌宠.bat”。
4. 首次运行会联网安装 PySide6；之后仍双击启动批处理即可。

退出：右键任意角色选择“退出桌宠”，或从系统托盘退出。

注意：这是可运行的第一版，角色为内置矢量立绘，带轻微待机浮动；暂不包含AI联网聊天或语音。程序不会读取桌面文件。
